五、安装方式

HOW TO INSTALL
A

方式一：技能商店一键安装（官方技能）

  1. 打开 Accio Work，点击侧边栏底部用户头像，选择「技能」；
  2. 在技能页面浏览「精选技能」或用顶部搜索框搜索关键词；
  3. 点击技能卡片上的「安装」按钮，技能自动下载并加入您的技能库。

快捷入口：工作台「Plugins」频道 → 左上角切换到「Skills」标签 → 点技能右侧「+」。

B

方式二：安装本地技能（本页技能压缩包）

  1. 点击上方按钮下载压缩包，并解压为技能文件夹（内含 SKILL.md）；
  2. 进入「技能」页面，点击「安装本地技能」；
  3. 选择解压后的技能文件夹完成加载，技能即刻生效。

提示：若技能包自带脚本/参考文档，请保持文件夹结构完整，不要单独移动文件。

📖 管理与配置：技能安装后可在「技能」页统一启用/禁用/卸载；也可进入「Agents」页 → 选择智能体 → 「管理技能」，为每个智能体单独勾选所需技能。 官方文档：Accio Work 技能管理文档
